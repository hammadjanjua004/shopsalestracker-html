# Baba Fruit and Juice Shop

A complete offline shop management system designed for small fruit and juice vendors. Built as a single HTML file with no external dependencies after initial load.

![Baba Fruit and Juice Shop](https://img.shields.io/badge/Status-Production%20Ready-brightgreen)

## Features

- **100% Offline Functionality** - Works without internet after first load
- **Bilingual Support** - English and Urdu interface
- **Inventory Management** - Track fruit and juice items
- **Sales Recording** - Log all transactions with quick-add buttons
- **Reporting Tools** - Export to Excel and PDF
- **Mobile Optimized** - Responsive design for all devices
- **No Installation** - Single HTML file runs in any modern browser

## Getting Started

1. Download the `baba_fruit_and_juice.html` file
2. Open it in any modern web browser (Chrome, Firefox, Edge, Safari)
3. Start managing your fruit and juice shop!

## Data Storage

All data is stored in your browser's localStorage. For backup:
- Use the built-in backup feature in Settings
- Keep copies of exported reports

## Offline Capability

The application works completely offline after first load with:
- Embedded service worker
- Local data persistence
- Cached external resources

## Usage Examples

- **Fruit Shop Management**: Track inventory and sales of fruits by weight
- **Juice Bar Operations**: Record sales by glass or container
- **Daily Reporting**: Generate end-of-day reports
- **Inventory Planning**: See what's selling to plan restocking

## Technical Details

- Built with vanilla JavaScript
- Uses localStorage API for data persistence
- Responsive design with CSS
- Font Awesome for icons
- XLSX library for Excel export
- HTML2Canvas + jsPDF for PDF generation
